# REST API Surface

Concise reference of every route under `app/api`. Generated by inspecting each `route.ts` file's exported handlers.

## /api/claude

| Path | Methods | Purpose |
|------|---------|---------|
| `/api/claude/agents` | GET | Parses recent session `.jsonl` tails to list Agent tool calls (background agent activity) |
| `/api/claude/brain` | GET | Aggregates every project's CLAUDE.md/config/hooks/commands/memory for the nav + Overview page |
| `/api/claude/claude-md` | GET | Returns the global `~/.claude/CLAUDE.md` content |
| `/api/claude/claude-md-history` | GET | Returns saved CLAUDE.md version history (and a specific version by id) |
| `/api/claude/claude-sessions/[sessionId]/input` | POST | Sends input text to a live terminal running a Claude session (iTerm2/VS Code) |
| `/api/claude/claude-sessions/[sessionId]/stream` | GET | SSE stream of a session's live transcript (text, tool calls, usage) |
| `/api/claude/context` | GET | Live per-session context-window usage for sessions with an attached process |
| `/api/claude/lan` | GET | Returns this machine's LAN IP, port, hostname, and model for discovery |
| `/api/proxy` | GET, POST | Same-origin reverse proxy to a peer dashboard's read APIs (multi-machine switcher) |
| `/api/claude/machines` | GET | Lists machines (local + any peers from MACHINES); ?discover=1 scans the LAN |
| `/api/claude/mcp-activity` | GET | Proxies MCP tool-call activity from the local-apps MCP bridge |
| `/api/claude/observability` | GET | System-health telemetry (traces/slow/failed calls) derived from agent task records |
| `/api/claude/project-icon` | GET | Resolves a project's favicon/app icon from local filesystem or local-apps cache |
| `/api/claude/search` | GET | Global search across sessions, memory, skills, commands, and CLAUDE.md files |
| `/api/claude/sessions` | GET, DELETE | Lists session history (cached, per-machine); deletes a session |
| `/api/claude/settings` | GET | Returns global/local `settings.json` (full dump if authorized, else key-count only) |
| `/api/claude/skill-usage` | GET | Skill/Agent tool_use usage stats parsed from session tails |
| `/api/claude/skills` | GET, PUT | Lists MCP servers/skills/commands/plugins; PUT updates a skill's config |
| `/api/claude/sync-skill` | POST | Writes a skill file to ~/.claude/skills |
| `/api/claude/token-stats` | GET | Token usage/cost aggregated across all sessions and models |
| `/api/claude/token-stats/daily` | GET | Daily token stats + hourly punchcard for the last 7 days |
| `/api/claude/tool-usage` | GET | Tool-call usage counts within a query window |
| `/api/claude/turns-by-hour` | GET | Per-day/per-hour turn counts for the activity punchcard |

## /api/rag

| Path | Methods | Purpose |
|------|---------|---------|
| `/api/rag/context` | POST | Assembles a context block (preferences + relevant chunks) for a given prompt |
| `/api/rag/docs` | GET | Lists ingested RAG documents |
| `/api/rag/docs/[id]` | GET | Returns one document plus its chunks |
| `/api/rag/eval` | GET, POST | GET: eval batch report (latest, by id, or per-question detail). POST: runs the eval matrix over all questions |
| `/api/rag/eval/questions` | GET, POST, DELETE | Manage the eval question set (list, replace/append, clear) |
| `/api/rag/health` | GET | Runs RAG subsystem health checks |
| `/api/rag/ingest` | POST | Discovers and ingests CLAUDE.md/memory/session/Obsidian sources into the RAG index |
| `/api/rag/insights` | POST | Extracts insights from ingested content (requires `ANTHROPIC_API_KEY`) |
| `/api/rag/mode` | GET, POST | Gets/sets the memory extraction mode setting |
| `/api/rag/preferences` | GET | Returns extracted user preferences by category |
| `/api/rag/search` | GET | FTS5 search over the RAG index, with optional semantic rerank |
| `/api/rag/stats` | GET | RAG index stats (doc/chunk counts, FTS benchmark timings) |

## /api/qr

| Path | Methods | Purpose |
|------|---------|---------|
| `/api/qr` | GET | Generates a QR code image for a given `?url=` (used for LAN sharing) |
